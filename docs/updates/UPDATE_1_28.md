# 1.28 — Native PlayStation controller fixes
For ReSkate 2.0.7

- Fixed gesture blocking for native DualSense and DualSense Edge controllers, including USB use with Steam Input disabled.

- Glance bindings now match Xbox behavior: the first press blocks the game gesture; a second tap within 250 ms allows it, including holding that second tap.

- Fixed gesture suppression for the configured first-person enter/exit controller hotkey.

- Preserved Xbox/XInput behavior.

Tested with DualSense, DualSense Edge, and XInput.
